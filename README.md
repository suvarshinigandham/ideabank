# 💡 IdeaBank
### Idea Sharing and Collaboration Platform

IdeaBank is a Flutter-based application that allows users to share innovative ideas, explore ideas posted by others, provide feedback, and collaborate with people who have similar interests.

## 🚀 Project Overview

IdeaBank provides a simple and interactive platform for users to:
- Share innovative ideas.
- Explore ideas across different categories.
- Like and save interesting ideas.
- Comment and provide feedback.
- Edit and delete their own ideas.
- View profile information and activity.
- Switch between light and dark themes.

## 🛠️ Technologies Used

- Flutter
- Dart
- Material Design
- SharedPreferences
- Git and GitHub
